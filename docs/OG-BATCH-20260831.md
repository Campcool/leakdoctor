# 全站 OG 圖片來源與檢查

日期：2026-08-31。業主同意整批設計方向後指示「開始生成，並上架」。本批 34 個新增主題各生成四版，保留候選後由 Codex 比較全幅與中央方形縮圖、選定正式圖；join 沿用業主已選 A，不重新生成。

## 範圍與限制

- 37 個公開 HTML 分頁（含文章）；不含 noindex 圖片製作工具 og-image.html 與 Google 網站所有權驗證檔。
- 新增 AI 圖只作情境示意，不能稱為實際客戶、指定師傅、施工紀錄或地方地標；圖片 alt 明示 AI。
- 案例頁與團隊頁使用既有去識別施作照片，原始 bytes 不變；團隊頁照片不保證特定人員出勤。既有 master 人像未作本批 OG 素材。
- 只做 JPEG 格式壓縮，未裁切或改寫既有照片。各頁填入真實圖片尺寸；中央裁切僅本機模擬預覽，LINE 實際卡片由平台決定。
- 不變更正文、CSS、JS、價格、canonical、robots、favicon、合作申請或 Bot。
- scripts/og-manifest.json 保存每頁檔案、來源、選版與生成提示詞；scripts/docs 不在 Pages 公開 artifact 中。

## 驗證方式

node scripts/check-og.mjs 驗證每頁 initial HTML metadata、唯一圖片、真實 JPEG 尺寸與大小。node --test scripts/test-og-contract.mjs 另以隔離 fixture 故意破壞缺圖、尺寸、Twitter、重複標籤及遺漏頁面確認可失敗。完整前台測試使用 --test-concurrency=1，避免既有 mutation tests 互相干擾。

正式部署仍需 GitHub Actions 成功，加上逐頁讀取正式 HTML 和圖片、核對圖片 SHA256；本檔記錄驗證方法，不把尚未執行的部署驗證當成完成。LINE 真機重新分享由業主驗收。

本機驗證結果：129/129 前台測試通過；37 頁 OG 契約通過；結構／品牌檢查及 34 個 sitemap 網址通過；前後台 29 項零售契約及水泥水塔三級距通過。另與 0c4a1de 比對（只正規化 Git/Windows 換行）：37 頁正文與非社群 head 設定未變，join 原有設定及既有照片保持不變。
