## ⛔ 先讀這段：目前有一個未解的落差，決定你今天怎麼投

**bot 的報價已經是新價，但官網 17 個頁面還是舊價。**

| 項目 | 官網現在顯示 | bot 現在報價 |
|---|---|---|
| 分離式冷氣 | $1,499 起 | **$1,599** |
| 直立式洗衣機 | $1,299 起 | **$1,599** |
| 吊隱式冷氣 | $2,599 起 | **$2,799** |
| 窗型冷氣 | $3,000 起 | **需報價（3 台以上才排）** |

這件事對廣告有兩個具體影響：

1. **Google 會比對廣告文案與到達網頁**。文案寫「$1,599 起」但網頁寫「$1,499 起」，可能被判「不實內容」而拒登。
2. 更實際的是：客戶在官網看到 $1,499、點 LINE 問卻被報 $1,599，第一印象就是被騙。

### 兩個選項，選一個

**選項一（建議，今天就能上線）：廣告文案完全不寫價格。**
本文件的 RSA 文案已經全部改成不帶價格的版本，主打「透明報價、加 LINE 先估價」。
先開跑，等官網改完再視情況把價格加回文案。**廣告效果影響很小**——以 LINE 諮詢為轉換目標的服務類廣告，價格通常不是文案裡最有效的鉤子。

**選項二：先改官網 17 頁的價格，再投帶價格的文案。**
需要改的頁面：`index.html`、`aircon.html`、`washer.html`、`areas.html`、`header.js`、
六個地區頁（`taipei` / `new-taipei` / `keelung` / `taoyuan` / `hsinchu` / `miaoli` / `taichung`）、
兩篇文章頁（`aircon-cleaning-cost` / `washer-cleaning-guide`）。
含 meta description、OG、JSON-LD 結構化資料、FAQ 內文與價格卡片。

> **我的建議是選項一先開跑**，官網改價另外排。廣告晚一天上線是機會成本，
> 文案跟網頁對不上被拒登、或客戶覺得被騙，是實際損失。

## 0. 動工前的唯一前提：轉換追蹤

1. **GA4 已上線**（`G-1H1X1X9QZE`）。確認 GA4「管理 → 事件」看得到 `quote_submit`、`line_click`。
2. 把 **`quote_submit` 標為關鍵事件**（主要轉換）、`line_click` 也標一個（次要／觀察）。
3. Google Ads「工具 → 資料管理 → 連結 Google Analytics (GA4)」連結資源 → **開啟自動標記（auto-tagging）**。
4. 從 GA4 **匯入轉換**：`quote_submit` 設**主要（Primary）**、類別 Lead、計算「每次一個」、
   價值先給固定 **TWD 500**；`quote_open`、`line_click` 設**次要（僅觀察，不給出價最佳化）**。
5. **不要**在網站貼 `AW-` 轉換碼、**不要**開 Enhanced Conversions（表單含電話／地址，未做隱私揭露前不外傳 PII）、
   **不要**用通話轉換（本站不放公開電話）。
6. 出價最佳化目標 ＝ `quote_submit`。追蹤沒好之前，出價先用「盡量爭取點擊＋出價上限」。
