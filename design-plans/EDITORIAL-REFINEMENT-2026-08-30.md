# 六服務閱讀版面精修

## 審視與範圍

業主以首頁、六服務流程、水管首屏、居家／水管價格表及水塔案例截圖要求綜合調整。依 UI/UX 指南先核對來源，再實作。保留六大服務、計價、案例事實、原流程安全說明及 LINE 接單行為；不修改 bot，不做正式訂單測試。

## 確認問題

- 同尺寸流程卡片塞入長段落，缺少閱讀主次；兩層 CSS 將白色號碼改成服務色，與深底撞色。
- `.headline-line` 強制 nowrap；大根字級時標題超出自己的 grid 欄，侵入圖片。
- 水塔案例的 inline aspect-ratio 分別為 3/4 和 1，同排圖片高度不同。
- 三欄表格受長報價文字擠壓，中文字詞拆斷；不能靠整表 nowrap 或縮小文字解決。
- 漏水頁同時有舊式承諾卡、流程卡；頁內錨點需考慮表頭與目錄實高。

## 視覺方案

流程改為「現場細節照片＋垂直閱讀序列」，每步短摘要常駐，原文放入原生 details。以細分隔線、留白和可見的開合符號提示互動，不再整排重複白色圓角盒。首頁四階段、設備頁六階段、居家三個預約步驟維持原意。採用既有真實現場素材並標示來源，不用生成圖冒充服務紀錄。

首屏採可收縮雙欄與合理行長，小尺寸或大字級改單欄；價格表按語意成組，窄版維持有欄名的卡片；案例使用等高影像框，影像不拉伸。漏水承諾改為橫向編輯式說明。

## 驗收

375／768／1440px、16／24px 根字級；必要時補 1024px 邊界。驗證無水平溢出、標題不碰圖、錨點不藏在導覽後、案例標題同高、原生展開鍵盤可用。保留修改前流程文案作回歸基準，測試加突變驗證。桌面尺寸模擬不宣稱 iOS／Android／LINE 真機通過。
