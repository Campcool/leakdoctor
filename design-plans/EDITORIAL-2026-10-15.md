# 灰汰郎品牌網站精修

設計 brief：協助台灣屋主／租屋族看懂服務、比較真實紀錄、確認費用；以既有實拍、六項服務及公開牌價為證據，採深藍與暖白的居家編輯風格，原生 HTML/CSS 實作。

## 基準與技能
- GitHub main 與本機同為 74da24d7ec281f69f10f8275faab136be7366655。
- 已透過 GitHub connector 讀取最新 uiux-design/SKILL.md（blob fc1100f1108d9827daa2a5781b5e7bcf7df69da4，含 2026-10-14 增補）及 playbooks/design-skills-integration.md。
- UI/UX Pro Max 查詢 local cleaning service trust editorial：採透明費用、真實案例、低摩擦入口；不採缺乏證據的認證／統計、不引入不支援繁中的字體。
- Taste 用於首頁構圖；保留 Noto Sans TC、品牌色、SVG 及原生框架。表單沿用既有三段流程。

## 畫面審計與改法
1. 首屏：舊 conversion-home.css 的冷藍色覆寫，與既有暖白／深藍品牌不同；手機標題實算 28.8px。改以深藍首屏、暖橘標題重點、明確價格 CTA 及完整實拍前後圖，建立主要視覺與資訊層級。
2. 服務選擇：home-service-hub.css 隱藏所有服務卡價格，讀者必須切換模式才比較。六項服務恢復原有價格提示，依服務名稱／處理範圍／價格／入口順讀；用雙欄編輯排列及原有服務圖示區別項目，不改品項或價目。
3. 案例與閱讀：首頁相鄰重複冷氣案例，前後圖 cover 裁切。保留原照及前後方向，以 contain 完整顯示證據；改善章節留白、字級、FAQ 與服務頁首屏／重點數字的統一性。

## 驗收
375／768／1440 截圖；另驗 320px、大字、reduced-motion、無JS。六服務頁的導覽、錨點、實拍圖、三段式詢價與首頁數量保留皆須回歸。API 與分析隔離，不建正式案件。以現有品牌／價格／流程測試與白名單產物驗證，未實測部分如實記錄。
