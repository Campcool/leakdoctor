# 灰汰郎 UI/UX 精修計畫（2026-08-30）

## 目標

把目前「內容完整但入口偏多、行銷語氣不一、手機首屏偏擁擠」的網站，整理成可信、好讀、能快速採取行動的知識型居家服務品牌；同時讓網站預約與 LINE 卡片使用同一套資訊層級。

## 實測基線

- 尺寸：1440×900、375×812；首頁、冷氣、居家清潔與預約表單。
- 優點：品牌色已穩定、服務頁已有專屬色、流程和價格資訊完整、觸控元件大致達 44px。
- 問題：桌機六個主頁籤使標誌與導覽競爭；手機頁籤缺少「可左右滑動」線索；首屏和表單同時提供太多選擇；首頁仍有偏廣告式或角色不清的文案；不同頁的 CTA、標題與資訊密度尚未完全一致。

## 設計方向

### 品牌論述

**先看懂，再處理。** 以「現象 → 判斷 → 處理 → 驗收」作為全站的辨識語法。避免保證式文案與空泛的「一站搞定」，改用可以驗證的服務邊界。

### 視覺語言

- 延用既有深海軍藍、暖橘、青綠與各服務專屬色，不另起一套模板。
- 標誌保持官網品牌形象，不做成按鈕或卡片。
- 主導覽只保留四個高頻服務大項；水塔與水管保留為完整服務頁及首頁入口，歸到水路相關資訊，不和品牌標誌搶首層空間。
- 卡片平時使用細邊框與極淺層次，互動時才增加陰影；不使用持續掃光或布局型動畫。
- 所有圖示使用現有 SVG sprite 或 LINE 官方視覺，不使用 emoji 充當功能圖示。

## 互動原則

- 固定表頭與頁內目錄不得遮住錨點內容。
- 手機主導覽可水平滑動，提供淡出提示並把目前頁籤帶入視窗。
- 預約表單採漸進揭露：先看必要資料與目前服務，設備型號／數量按需展開。
- 表單錯誤訊息清楚、焦點可見、關閉後焦點回到原按鈕；支援 Escape 與瀏覽器返回關閉。
- 動態只使用 `transform` / `opacity`，並尊重 `prefers-reduced-motion`。

## 本輪實作範圍

1. 重整全站固定表頭、主導覽、跳至內容與焦點樣式。
2. 統一首頁和六個服務頁的文案、按鈕、卡片、標題與閱讀寬度。
3. 精簡預約視窗的視覺密度與說明，維持既有案件 API。
4. 修正文案錯字、重複屬性、emoji 功能圖示與不一致稱呼。
5. 統一客戶 LINE Flex：較寬卡片、短段落、狀態標籤、明確主次按鈕。
6. 通過現有網站驗證、Bot 測試與桌機／平板／手機視覺複核。

## 驗收標準

- 375、768、1024、1440px 無水平頁面溢位；導覽與 CTA 可辨識。
- 文字正文維持可讀行長，手機不出現小於 14px 的主要操作文字。
- 所有互動可由鍵盤操作，焦點清楚；減少動態模式下無持續動畫。
- 預約表單可成功建立案件；服務可用性 API 失敗時仍能 LINE 直接詢問。
- LINE Flex 可通過既有型別與測試，重要內容不依賴 emoji 才能理解。
